# 浮岛 · Luo1631

云海上方的实时 3D 浮岛。针叶树撑起后岸轮廓，暖橙土径从岛缘拐向浅湾。池里的天鹅和鱼穿过岸树的倒影，水帘从岛侧落向海面。岸边有人和狗，猫在青瓦木屋与池岸之间走动。

## 运行

在本目录使用 Node.js 22.12 及以上版本。开发服务使用 5175 端口，可直接打开 [浮岛](http://127.0.0.1:5175/)。

```sh
npm run dev
npm test
npm run build
npm run check:release
```

默认随浏览器本地时区显示天色，也可在底部切换白天和夜晚。鼠标拖动环看，滚轮以指针下的区域为中心缩放。触屏支持滑动和双指缩放。画面获得键盘焦点后，方向键环看，加减键缩放，Home 键复位。

底部的「编辑」提供种树和放石。鼠标单击可放置，右键拖动可环看。触屏轻点放置，滑动环看。树落在陆地，岸石可落在湿岸或浅水。画面获得键盘焦点后，Enter 在画面中心放置，Esc 收起编辑。刷新页面会重新载入预置场景。

## 瀑口垂钓

点击发白光的木舟或右上角「钓鱼」，人物会在瀑口的岸石坐下抛竿。5–10 秒后咬钩，单击画面或按 Enter 收竿。三轮共用一个 1–999 的答案。每轮自动聚焦数字框，输入满三位、按 Enter 或到 2 秒时提交，屏幕会提示偏高、偏低或猜中。触屏提供独立数字键盘。

最接近的一猜影响最大，三轮整体表现也计入概率。猜中时 S 级概率为 23%，A 级为 34%。三轮均未输入有效数字时钓到 E 级。同一等级内，尚未发现的鱼种有 1.6 倍抽取权重。背包保留每次鱼获，图鉴汇总鱼种、参考体长和体重、个人最轻和最重记录。数据按站点地址保存在当前浏览器。

图鉴收录 140 种、覆盖 98 科。加州科学院《Eschmeyer’s Catalog of Fishes》的公开分类表于 2026-11-26 列出 624 科。图鉴详情标注所属科，搜索支持中文及拉丁科名。 [鱼类科分类体系](https://www.calacademy.org/scientists/catalog-of-fishes-classification/) · [鱼种和参考体重](src/floating-island/fishing-catalog.ts)

本批从此前未收录的 40 科各选一种。所选调查公开了采样地区、样本量、实测尺寸范围和体长—体重回归，37 种的样本量达到 30 尾。参考体重取该调查实测尺寸范围内一点的估计值。展开「研究样本」可核对这些信息和拟合优度 R²，原表有列的实测体重范围也一并显示。 [调查数据](src/floating-island/fishing-surveys.ts) · [普图马约河调查表 1](https://onlinelibrary.wiley.com/doi/10.1155/jai/3116845)

知名度、野生珍稀度和受欢迎程度各人工评 1–5 分并等权相加。同分时先按珍稀度、再按受欢迎程度排序。S–E 依次占鱼种总数的 5%、10%、15%、20%、25%、25%，分别为 7、14、21、28、35、35 种。参考体重采用科研回归、标本实测或公开的样本均值，图鉴逐种标注出处和测量口径。 [东热带北大西洋中层鱼调查](https://doi.org/10.1111/jfb.15068) · [罗斯海黑角鮟鱇个体实测](https://polarresearch.net/index.php/polar/article/view/3249) · [NOAA 太平洋远洋鱼调查](https://repository.library.noaa.gov/view/noaa/9081/noaa_9081_DS1.pdf)

个体体重按以参考体重为中心、标准差为 11 个百分点的正态分布采样，再限幅到 ±25%。偏差绝对值不超过 1% 为超级标准，超过 1% 至 7.5% 为标准，超过 7.5% 至 20% 为大或小，超过 20% 为超级大或超级小。到达 ±25% 时记为最大 Max 或最小 Min。已钓到的鱼也按当前规则显示鱼种等级和体型。 [科研数据](src/floating-island/fishing-catalog.ts) · [抽取和体型规则](src/floating-island/fishing-rules.ts)

## 场景制作

- 岛沿剖面从草皮、薄土过渡到蓝紫色岩壁。地表遮罩把土径覆盖率、水域和岸线深浅读数对齐到同一世界坐标，植被按相同岸线和路径函数布置。岸石从不规则块体内缩切面，生成倒角和苔斑。 [岛体与地表](src/floating-island/terrain.ts) · [岸石与崖石](src/floating-island/rocks.ts)
- 针叶主树由数层垂枝与细齿枝片撑起，圆冠小树和桃树沿细枝长出叶簇和五瓣花。草甸用细叶短草打底，灌木和边缘分布高草。草、花按种类实例化，草叶的顶端随风摆动。 [树木](src/floating-island/trees.ts) · [草与花](src/floating-island/planting.ts)
- 池水用同一水位衔接浅滩，岸树和岸石的反射在镜头、天色或布置变化时刷新。天鹅的尾迹随游速变化，木舟在系缆范围内摇晃。瀑布卷过池口后收成主水帘与三道细流，末端融进瀑脚白沫和低雾，涟漪从落点向外散开。薄云随天色变化。 [池水、瀑布与海面](src/floating-island/water.ts) · [木舟和缆绳](src/floating-island/skiff.ts)
- 人沿小径往返观湖，狗在邻侧跟行并去草边嗅闻，猫沿屋前和池岸之间的路线观察、休息。迈步时按地面高度算落脚。天鹅在湖心游动和停歇，四条鱼各自巡游，在水下让开天鹅和舟。 [活动路线](src/floating-island/habitat-motion.ts) · [岸上角色](src/floating-island/shore-life.ts) · [水下鱼群](src/floating-island/fish.ts)
- 正交相机使用同一套环绕和拾取地形。暖主光、冷环境光和金色萤火共用色调映射与 sRGB 输出。阴影按天色和岸石变更刷新。浏览器启用减少动态时，草、云、萤火、湖瀑和角色活动定格，镜头和天色可以手动操作。 [镜头、灯光与拾取](src/floating-island/scene.ts)

运行开发服务后，`npm run posters:capture` 可从真实入口重拍宽屏和窄屏昼夜静图，用于加载和 WebGL 回退。捕获工具可用 `CHROME_BIN` 指定浏览器。发布检查要求四张实际场景静图和完整的独立入口。

## 验收

### 瀑口垂钓

2026-11-25 从 1080 × 608 的生产入口实点木舟，两次分别在 5.24 秒和 6.19 秒后咬钩。验证了左键和 Enter 收竿，以及三位数自动提交、Enter 提前提交、两秒到时提交。三轮超时仍获得 E 级鱼。鱼获写入后可在背包和图鉴查看，刷新后仍可打开。在 390 × 844 的 Chrome 触控模拟中走完数字键盘、再钓一次和中途退出。

Windows RTX 4060 Laptop GPU 的短时采样中，默认视角与瀑口近景的帧间隔中位数分别为 7.6 ms 和 7.5 ms，P95 为 8.4 ms 和 8.1 ms，draw calls 中位数分别为 197 和 134。近景改变了画面内的场景范围。15 项测试、生产构建和发布检查均通过。

2026-11-26 在 1080 × 608 生产预览核对 100 种鱼的六档数量，并用中文和拉丁文科名搜索。用旧格式样本核对 +1%、−7.5%、−7.51% 的体型边界。以固定随机值走完点船和猜数，成功获得 S 级约氏黑角鮟鱇并在刷新后找回。在 390 × 844 预览核对科名和参考测量的显示。17 项测试、生产构建和发布检查均通过。

同日扩充到 140 种、98 科。对照加州科学院公开分类表核对 98 个科名。在 1080 × 608 与 390 × 844 的生产预览核对中文及拉丁科名搜索、研究样本展开和测量口径。以固定随机值走完木舟到瀑口的钓鱼流程，钓获刀鲚并打开研究样本，刷新后在背包找回刀鲚及旧鲫鱼记录。18 项测试、生产构建和发布检查均通过。

### 云海与湖边活动

2026-11-25 从 1080 × 608 的生产入口核对了昼夜全景、瀑布落海、天鹅羽缘、池底鱼影和木舟系缆。运行约 38.5 秒覆盖猫的一轮行程，并在中途截图核对人狗同行、狗低头嗅闻和猫在岸边停留。路线测试覆盖地面落脚、人狗间距、天鹅距船壳的间隙和鱼鳍的水面与池底高度。

同一台 Windows RTX 4060 Laptop GPU 上，Chrome 158 在 DPR 1 下采样 6,351 个活动帧。帧间隔中位与 P95 均为 6.1 ms。固定机位的 draw calls 中位数为 195，更新反射时的峰值为 256。另走过放石、种树、环绕、缩放和键盘复位。在 390 × 844 触控模拟中核对点放和捏合，关闭 WebGL 后加载新版静图。`npm test`（9 项）、生产构建及发布检查均通过。

细化瀑布后，从 1080 × 608 的生产入口查看白天和夜晚近景，复测环看、缩放、键盘及触控复位、减少动态和静图回退。固定机位帧间隔 P95 为 6.1 ms，draw calls 中位数为 195。四张昼夜静图同步更新。

### 林间浮岛与点放

2026-11-25 用 1080 × 608 的生产预览对照参考视频的开场与 00:32–00:39，核对主树层间、细草与高草、桃花枝、岸石接地和水线。用实际鼠标输入先放一块岸石、种一棵小树，再连续点放 18 块岸石，右键环看并滚轮缩放。方向键、Home、Esc 和复位均已验证。屏幕叠层的空白让指针穿过，窄屏节流在首帧初始化后生效。在 390 × 844 触控模拟中通过点放、捏合和复位，WebGL 不可用时加载更新后的静图。

Windows Chrome 158 无头模式使用 RTX 4060 Laptop GPU 的 D3D11 硬件渲染，DPR 为 1。帧间隔来自 `requestAnimationFrame`，CPU 耗时覆盖每帧场景回调，draw calls 为实际 WebGL 调用并计入阴影通道。本次连续点放共采样 309 帧，最长帧间隔为 6.2 ms。

### 此前的场景记录

2026-11-25 从 Chrome 打开构建产物，核对桌面日夜、鼠标与键盘环看缩放、复位，以及 390 × 844 触控模拟的捏合。用同一个时刻在 Asia/Shanghai 和 UTC 核对自动天色，并验证 WebGL 不可用时会按天色显示窄屏静图。分别从独立入口和原有 2D 魔方到达新场景，返回后继续使用原历史记录。122 条现有单元测试、生产构建和发布检查均通过。
