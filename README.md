# 栖屿 · Luo1631

栖屿是一座由 Three.js 实时生成的三维池塘。可独立打开，也可从游境首页的魔方进入。

## 运行

使用 Node.js 22.12 及以上版本。在栖屿目录运行以下命令。

```sh
npm ci
npm run dev
npm test
npm run build
npm run check:release
```

开发服务使用 5175 端口。测试返回入口时，同时运行 5174 端口的游境。[打开栖屿](http://127.0.0.1:5175/) · [打开游境](http://127.0.0.1:5174/)

## 跳转与发布

从魔方来的访客继承游境语言，页面左上「返回」会回到原来的浏览器历史记录。直接打开栖屿时，「返回」跳到配置的游境首页。开发默认指向 5174 端口，生产默认指向同域根路径。独立域名发布时，在 .env.production.local 设置 VITE_YOUJING_URL 为游境的正式地址，再重新构建。

发布栖屿自己的 dist 目录。相对资源路径支持从域名根目录或 /qiyu/ 子路径加载。部署到子路径时，托管环境需要同时映射入口 HTML 和 assets 目录。[本地 Wrangler 配置](wrangler.jsonc)

## 场景与玩法

点水引船，鼠标划过或手指拖动可拨水。双击小岛进入近景。双击小舟或在触屏上轻点小舟两次，可以从贴近水面的机位随船看景。随船时用右键拖动或双指拖动环顾，仍可点水改航。全景中右键拖动或双指拖动平移，按住 Shift 右键拖动转向。两种视角都能用滚轮或双指捏合缩放，右下按钮回到全景。[从本地打开栖屿](http://127.0.0.1:5175/) · [随船回归](tests/pond-ride.browser.py)

桃花瓣会落水漂浮，船灯和石灯可以开关，风铃会摆动并响起短音。轻点荷叶会压下叶缘并泛起水纹，轻点天鹅时它会转头朝向当前视角。船猫会循着近处的水声动耳、转头。右上可以暂停动态或切换昼夜，左下问号可重新打开玩法提示。键盘聚焦池塘后可用加减键缩放，方向键平移或环顾，Q 和 E 转向，1 到 3 近看小岛，4 跟船，0 回全景。回车点水，L 点石灯，B 点船灯，C 摇铃，P 摇落花瓣。

栖屿的岛岸、建筑、植被、远山、动物、小舟和乘客均由 Three.js 生成。天鹅的颈部和躯干连续成形，同一副分层羽翼随动作收拢或展开。船上的搭接板、桨、灯和乘客共用随波起伏的船体。首页圆窗使用自己的物象和日夜小像。[小舟建模](src/scene/PondBoat.ts) · [天鹅建模](src/scene/PondSwan.ts) · [资源隔离回归](tests/pond-assets.browser.py)

远岸的落叶树和冷杉有独立的分枝形态，按实际坡面落根。岛岸在碎砾、湿沙和水下沉积之间过渡，浅水焦散随阳光折入水中的方向变化。[远山](src/scene/PondVista.ts) · [林带建模](src/scene/foothill-trees.ts) · [岸床材质](src/scene/PondSediment.ts)

从栖屿入口进入时，桌面和触屏都使用完整几何与浏览器提供的原生像素密度。动态画面使用 4096 × 4096 的阴影贴图，反射与折射按画布像素尺寸逐帧更新，实际纹理尺寸受显卡支持范围约束。发布检查核对入口、资源完整性和旧模型隔离。[渲染设置](src/scene/render-profile.ts) · [水面渲染](src/scene/PondWater.ts)

日月按来访时刻算出方位，天空和水镜使用同一份天光。日落后朝落日方向的低空保留暖光，天顶逐步转蓝。需要对照时可从固定机位看暮色、月升和岸树。[暮色](http://127.0.0.1:5175/scripts/design/scene-review.html?date=2026-11-23&time=17:20&view=dusk&clean=1) · [月升](http://127.0.0.1:5175/scripts/design/scene-review.html?date=2026-11-23&time=17:20&view=moonrise&clean=1) · [岸树](http://127.0.0.1:5175/scripts/design/scene-review.html?time=12:30&view=grove&clean=1)

栖屿在加载和 WebGL 回退时按昼夜、朝向显示实景截图。系统减少动态时以静止状态进入实景，用户可播放。运行本地开发服务后，`npm run posters:capture` 用 Chrome 重拍四张 WebP，可设 `CHROME_BIN`。[日景](public/pond-poster-wide-day.webp) · [夜景](public/pond-poster-wide-night.webp)

### 场景制作

小舟、乘客、天鹅及岸边植被的现行模型随实景在浏览器生成。开发服务启动后，可用固定机位查看实景，或重拍昼夜加载图。[实景审阅](http://127.0.0.1:5175/scripts/design/scene-review.html) · [海报脚本](scripts/design/capture-posters.mjs)

旧版 Blender 制作脚本可用于复查历史模型。涉及旧场景导出、接触检查或参考贴图的命令需要准备对应的 Blender 母版、GLB 或参考素材。使用系统 PATH 中的 Blender，或通过 `BLENDER_BIN` 指定可执行文件。[制作脚本](scripts/models)

### 旧版实景制作记录

- 岸床同泥沙，砂缘随坡深，簇草嵌石。折射按深度，焦散随日照。五坡草石贴床，主石投影。两端减 63552/10774 面，草根采波。三侧添荷、池心两叶两花。船绕荷巡湾，左岸钓桥 4.49 米。
- 容与岛双枝桃冠罩六角亭，亭口斜朝右泊位。岛岸1.5×、树1.3×、亭约.8×。枝根焊合回投顺纹。桃冠加厚中后层，树冠错落叠簇，绘纹随视距淡出。[饱满桃冠参考](scripts/design/rongyu-foliage-reference-v2.png)
- 地被由根部舒展的圆叶簇替代平铺团块，野花夹在叶间。岸草收尖，地色随栽植，留沙滩及栈桥口。灌木、地被简模保根位。荷叶花瓣压高光，47茎合批。核固定机位、贴地与泊位净空。
- 草根、岸石、桌椅、牌脚贴 Blender 岛坡，书页有厚度。动物岛收远侧、塑背坡、簇植，断枝贴坡留龟滩。四岛波场遮罩贴水线。核桥桩、踏板、船位，灯源对铜框灯罩。信箱转 35° 朝栈桥，核通槽、旗轴、铰链、盆根。屏座补轴，键帽 1,716→780 面。
- 鲤摆尾斜升、收鳍跃水受重力水阻；龟外蹼转弧、踩岸骑背；蛙蹬滑蓄跳、蜻蜓变速展足贴叶。天鹅让船、蹬水巡飞滑降，溅滴起波。猫连颈胸、稳爪呼吸、抖耳，点近水抬头动尾。原回导68姿态，节奏人审。
- 反射折射分缓存/随视口取景。日影采世界距/日斑软边，暮色余光。夜增冷补光/暖灯/星光，日月影随波。水下岛坡可点。1440×900 同机位两组 P95 13.3–15.7→10.1–10.4 ms。大包警告，真机功耗/长时帧待测。
- V14 脸，短腰腹、掌心向上半枕后脑。低枕厚垫，掌脚贴合，收艏艉后整组放大 1.2 倍。
- 船速定转向、尾波，近点短划、撤推滑行。船兽共用姿态投影。种子 731 本机 9,000 步 1.00→0.14 ms/步、569 接触、终点同。扫掠粗筛、岸路复用，百条约 200→75 ms。
- 岸床八叉树调叶容量，深度图、池底网格重建中位约 192→141 ms，字节一致。岸线遮罩 512² 约 35→9 ms，256² 输出同。浮力复用半精度换算，CPU 解码约 0.24→0.027 ms/次。核 GPU 异步读回、过岸遮挡。
- 波场边长 64→40 米。桌面 320²、移动 160²，格距仍 12.5/25 厘米。两端 GPU 各 350 步，重叠波高逐格一致，更新像素减 61%。
- 草丛倒影、阴影共用风形变。外岸沿水线拆批，折射约 34.20→3.68 万面/次。低画质留树、灌木、岛草投影。390×844 暮色阴影约 32.7→18.6 万面/帧，P95 约 39 ms。
- 诗集与 Three 分载，等船可进岛，审阅等齐模型。模拟 10 Mbps、65 ms，桌面夜图、实景、船各约 3.9→2.7–2.8、14.2→11.7–11.9、13.9–14.5 秒显示。固定灯数复用折射程序。本机两组延载船，额外链接 39→8，首绘长任务 1.21–1.33→0.15–0.21 秒，准备约 0.19 秒。
